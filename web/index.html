Leo Li+ Studio Release Notes

Computational Mechanics Solver v1.5.0 更新公告

同步二维动力学世界

本次 Alpha 更新加入真实平动与转动状态，并将需要接触求解的对象放入同一二维物理世界。

  • 真实计算角度、角速度、角加速度、质心惯量和力矩。
  • 支持质心、局部偏移和世界坐标作用点；偏心力与冲量同时改变平动和转动。
  • 支持圆—圆、圆—地面接触，以及恢复、静/动摩擦、阻尼、多接触迭代和穿透修正。
  • 自适应子步会把强外部加速度纳入防穿透估计；超过计算上限时安全停止。

轨道、滚动与安全变化场

  • 支持直线、斜坡、折线、圆弧和三次 Bezier 平滑轨道。
  • 支持质点滑动、实心圆盘无滑动滚动、滑动转滚动、端点停止/反弹/释放和离轨状态。
  • 重力、电场和二维垂直磁场支持常量、时间、空间和时间—空间表达式。
  • 表达式使用受控 AST 与白名单求值，不执行工程文件中的 JavaScript 或 Python 代码。

工程、界面与账户权益

  • 动力学工程升级到 cms-dynamics-project@2，打开 v1 工程时自动迁移，旧力与冲量默认作用于质心。
  • 保存、打开和撤销会保留角状态、接触材料、作用点、地面、轨道、约束和变化场。
  • 报告新增角运动、接触和轨道信息，并提供碰撞、轨道滚动、变化场三个 v1.5 示例。
  • 账户与 Free、Plus、Pro、Internal Tester、Admin 权益改由服务器管理；Internal Tester 不继承 Admin。
  • Plus/Pro 暂不提供购买，PINN 仍为等待名单且不会解锁求解器。

验证与发布状态

Python、JavaScript、数据库、HTTP、安全和物理验证均已通过发布前回归。当前仓库已统一为 v1.5.0，但本次清理不会自动推送 GitHub，也不会连接或更新云端正式服务。

v1.5.0 新功能请参考本更新公告和 RELEASE_NOTES_v1.5.0.md。《Computational Mechanics Solver v1.3.2 用户与技术说明书》仅作为历史版本说明书继续提供下载，不完整覆盖云账户、权益、碰撞、刚体转动、约束轨道和变化场。

当前限制

轨道对象尚未与自由/接触对象进入同一碰撞世界；离轨或开放端点停在事件状态，不继续剩余时长的自由飞行。碰撞仅支持圆和显式正碰撞半径的质点；变化场未声明势函数时不提供势能或机械能结论。Alpha 结果不应用于未经独立复核的工程安全决策。
